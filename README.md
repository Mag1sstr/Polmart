# Polmart

## Описание проекта

**Polmart** — веб-приложение для представления продукции и управления информацией о товарах. Проект включает клиентскую часть, серверную часть и API для работы с товарами, категориями, новостями, галереей, заказами и консультациями.

## Используемые технологии

### Frontend
- **React** — библиотека для создания пользовательского интерфейса.
- **JavaScript** — основной язык программирования клиентской части.
- **HTML5 / CSS3** — разметка и оформление интерфейса.

### Backend
- **Node.js** — среда выполнения JavaScript на сервере.
- **Express.js** — фреймворк для создания API и обработки HTTP-запросов.
- **MongoDB** — документоориентированная база данных для хранения информации.
- **Mongoose** — библиотека для работы с MongoDB (если используется в проекте).

## Установка и запуск проекта

### 1. Предварительные требования

Перед началом работы необходимо установить:

- [Node.js](https://nodejs.org/)
- npm (устанавливается вместе с Node.js)
- [MongoDB](https://www.mongodb.com/) или доступ к MongoDB Atlas

### 2. Установка зависимостей Backend

Откройте терминал в корневой папке проекта и выполните команды:

```bash
cd server
npm install
```

### 3. Настройка переменных окружения Backend

Создайте файл `.env` в папке `server` и укажите необходимые параметры подключения к базе данных и настройки сервера.

Пример:

```env
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/polmart
```

Названия переменных должны соответствовать тем, которые используются в серверном коде. При использовании MongoDB Atlas укажите соответствующую строку подключения.

### 4. Установка зависимостей Frontend

Откройте второй терминал и выполните:

```bash
cd client
npm install
```

### 5. Запуск сервера

В первом терминале перейдите в папку `server` и выполните команду запуска, указанную в `package.json`.

Например, если настроен скрипт `start`:

```bash
npm start
```

Для запуска в режиме разработки, если предусмотрен соответствующий скрипт:

```bash
npm run dev
```

Сервер будет доступен по адресу `http://localhost:5000`, если в настройках указан порт 5000.

### 6. Запуск клиентской части

Во втором терминале выполните:

```bash
cd client
npm start
```

Если проект создан с помощью Vite и в `package.json` настроен соответствующий скрипт, используйте:

```bash
npm run dev
```

После запуска откройте адрес, указанный в терминале. Для Vite это обычно `http://localhost:5173`, а для Create React App — `http://localhost:3000`.

## API-маршруты

Сервер предоставляет REST API для работы с основными сущностями приложения. Маршруты подключаются через Express с помощью `app.use()`.

Базовый адрес API при локальном запуске:

```text
http://localhost:5000/api
```

| Маршрут | Назначение |
|---|---|
| `/api/products` | Работа с товарами: получение списка, просмотр и управление товарами в соответствии с реализованными обработчиками. |
| `/api/categories` | Работа с категориями товаров. |
| `/api/news` | Получение и управление новостями. |
| `/api/gallery` | Работа с изображениями и материалами галереи. |
| `/api/admin` | Административные операции и функции управления. |
| `/api/orders` | Работа с заказами. |
| `/api/consults` | Работа с заявками на консультацию. |
| `/uploads` | Доступ к загруженным файлам и изображениям. |

### Примеры запросов

Получение списка товаров:

```http
GET /api/products
```

Получение списка категорий:

```http
GET /api/categories
```

Получение новостей:

```http
GET /api/news
```

Получение изображений галереи:

```http
GET /api/gallery
```

Работа с заказами:

```http
GET /api/orders
```

Работа с заявками на консультацию:

```http
GET /api/consults
```

Доступ к загруженному изображению:

```text
http://localhost:5000/uploads/example.jpg
```

**Примечание:** приведённые примеры показывают базовые пути API. Доступные HTTP-методы, параметры и конкретные операции зависят от обработчиков, реализованных в соответствующих файлах маршрутов. Для административных маршрутов могут требоваться авторизация и дополнительные права доступа.

## Принцип работы приложения

1. Пользователь взаимодействует с интерфейсом, созданным на React.
2. Клиентская часть отправляет HTTP-запросы на сервер.
3. Express обрабатывает запросы через соответствующие API-маршруты.
4. Сервер взаимодействует с MongoDB для получения или изменения данных.
5. Результат возвращается клиентской части в формате JSON, а загруженные изображения доступны через маршрут `/uploads`.
